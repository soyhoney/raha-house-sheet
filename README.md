# 라하 하우스 예약관리 시트

이집트 다합의 게스트하우스 **라하 하우스**에서 쓸 예약·정산·통계 시트입니다. 지점 3곳, 객실 6개, 침대 12개 규모예요.
기존 시트는 날짜마다 손님 이름을 직접 치고 할인표를 따로 다시 입력하는 방식이었어요. 이걸 **예약 1건을 한 줄만 입력하면 나머지가 자동으로 나오는 구조**로 바꿨습니다.

📥 파일
- [`라하하우스_예약관리_2027.xlsx`](라하하우스_예약관리_2027.xlsx): 실제로 쓸 빈 시트예요. 형식을 보여주는 예시 1줄이 들어 있어요.
- [`라하하우스_예약관리_2027_예시데이터.xlsx`](라하하우스_예약관리_2027_예시데이터.xlsx): 시연용으로 2027년 1~2월 예약 10건을 넣었어요. 손님 이름은 모두 지어낸 거예요.

구글시트에서 **파일 → 가져오기 → 업로드**로 열면 됩니다.

## 기존 시트에서 발견한 문제

| 문제 | 예 |
|---|---|
| 할인표에 객실타입을 다시 쳐서 생긴 오입력 | 2인실 손님이 3인실 요금으로 계산돼 매출이 적게 잡힘 |
| 같은 할인인데 할인율이 다름 | 같은 장기할인인데 한 명은 20%, 다른 한 명은 10% |
| 안내문과 시트 규칙이 다름 | 다이빙 할인을 "교육 일수"가 아닌 "숙박일수"로 계산, 중복 할인 기준도 달마다 다름 |
| 수식 오류 | 4호점 정원 월 합계가 90이 아니라 3으로 표시 |
| 월을 넘어가는 숙박이 쪼개짐 | 63박 손님이 9월 1박, 10월 31박으로 따로 입력돼 할인 판정이 어긋남 |
| 없는 정보 | 연락처, 예약경로, 입금, 환불 |

## 탭 구성

| 탭 | 역할 |
|---|---|
| **예약** | 유일하게 입력하는 탭이에요. 상태, 이름, 성별, 연락처, 경로, 객실, 체크인·아웃, 할인 체크, 입금, 취소일을 넣으면 박수, 기본금액, 할인, 최종금액, 미수금, 환불액이 자동으로 나와요 |
| **달력** | 월을 고르면 객실 × 날짜 칸에 이름(성별)이 채워져요. 🟨 일부, 🟩 만석, 🟥 정원 초과, 🟪 혼성으로 표시되고, 객실별·지점별로 남은 침대 수도 나와요 |
| **통계** | 월을 고르면 순매출, **지출, 순이익**, 할인 전 매출, 할인 합계, 가동률, 손님 수, 평균 숙박일이 나와요. 할인 종류별, 지출 항목별, 객실별, 예약경로별 표와 연간 추이(순매출·지출·순이익 그래프), 미수금, 취소 위약금도 볼 수 있어요 |
| **지출** | 월마다 한 줄로 가스, 전기, 수도, 인터넷, 수리, 비품, 기타를 **EGP로** 입력해요. 환율 칸을 비우면 설정 탭의 기본 환율로 원화로 바꿔요 |
| **설정** | **기간별 요금표**, 정원, 할인 기본값, 환불 규칙, 예약경로 목록, 기본 환율이에요. 요금이 바뀌면 여기만 고치면 돼요 |

## 계산 규칙

```
최종금액 = (기본금액 − 다이빙 할인) × (1 − 장기% − 재방문%) − 기타 조정
```

- **1박 요금은 체크인 날짜 기준**: 설정 탭 요금표에서 "적용 시작일 ≤ 체크인 날짜"인 가장 최근 줄의 요금을 숙박 전체에 적용해요. 요금이 바뀌는 날에 걸쳐 묵어도 체크인 날 요금이 유지돼요(예: 6/25~7/5 → 10박 모두 6월 요금). 요금을 바꿀 때는 새 줄을 추가하면 지난 예약 금액은 그대로 남아요.
- **다이빙 연계 할인**: 교육 일수 × 3,000원. 제일 먼저 차감해요.
- **장기 할인**: 기본 10%, 예약마다 바꿀 수 있어요. 10박 미만이면 경고가 떠요.
- **재방문 할인**: 기본 20%, 예약마다 바꿀 수 있어요.
- 할인을 몇 개 줄지는 관리자가 정해요. 시트는 체크된 할인을 모두 합산해서 계산해요.
- **환불**: 체크인 15일 전까지 100%, 7~14일 전 60%, 6일 전부터 0%
- **월 매출**: 여러 달에 걸친 숙박은 묵은 날 수만큼 나눠서 각 달에 잡아요. 확정 예약만 포함돼요.
- **가동률**: 묵은 박수 ÷ (침대 수 × 그 달 날짜 수)
- **순이익** = 순매출(할인 뺀 매출) − 지출(EGP × 환율)

## 경고 (예약 탭 "확인 필요" 칸)

정원 초과 · 혼성 배정 · 미입금 · 10박 미만 장기할인 · 교육일수 없음 · 날짜 오류 · 필수칸 누락 · 취소일 없음

정원 초과와 혼성 배정은 **늦게 들어온 예약** 쪽에 표시돼요. 그 예약을 옮기면 해결된다는 뜻이에요.

## 다시 만들기

```bash
pip install openpyxl
python build.py 라하하우스_예약관리_2027.xlsx
python build.py 라하하우스_예약관리_2027_예시데이터.xlsx sample
```

구글시트와 엑셀에서 똑같이 동작하도록 SUMPRODUCT, COUNTIFS, TEXTJOIN 위주로 만들었어요. FILTER처럼 최신 함수나 `"<>"`(빈칸 아님) 조건은 쓰지 않았어요.
